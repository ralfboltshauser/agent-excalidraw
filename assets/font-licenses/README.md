# Font and editor license evidence

See [the third-party notice](../../docs/THIRD_PARTY_NOTICES.md) for the redistribution inventory and provenance. Keep this directory in packaged distributions alongside that notice.

* `*-OFL.txt` files retain full SIL Open Font License 1.1 terms and the associated upstream copyright notices.
* `ComicShanns-MIT.txt` is extracted verbatim from the SDK font's name table.
* `Excalidraw-MIT.txt` is the editor's pinned upstream software license.
* `bundled-font-metadata.json` inventories all 234 upstream WOFF2 inputs, not the final package. One original input is deliberately replaced with the separately recorded Agent Sans derivative.
* `Xiaolai-source-notice.txt` preserves the SDK's source metadata and modification notice.
* `source-urls.json` records immutable upstream text sources.
* `Liberation-LICENSE.txt` and `Liberation-GPL-2.0.txt` are historical audit references for the SDK's legacy fallback; the original 1.05 font must be excluded from distributed artifacts in favor of the verified OFL replacement.

Font metadata can contain historical copyright statements or vague URLs. The linked full source licenses and version-specific provenance explain the evidence rather than inferring a font license from the package's MIT metadata.
